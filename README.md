MaternalAI is a specialized full-stack application designed to predict maternal delivery outcomes using machine learning. Developed in collaboration with **Azhar Nawaz** and team (Final Year Pharmacy Students), this platform integrates pharmaceutical expertise with state-of-the-art AI.

![MaternalAI Banner](https://images.unsplash.com/photo-1584036561566-baf8f5f1b144?q=80&w=2000&auto=format&fit=crop)

## ✨ Features

- **🤖 AI Diagnostics**: Real-time Random Forest classification for delivery mode risk assessment.
- **📊 Analytics Dashboard**: Interactive visualizations of physiological data and model performance.
- **🔐 Secure Access**: Localized authentication system ensuring data integrity.
- **📄 Clinical Reports**: Print-ready diagnostic reports for clinical documentation.
- **📱 Responsive Design**: Fully optimized for mobile, tablet, and desktop viewing.

## 🛠️ Tech Stack

- **Frontend/Backend**: [Next.js 14](https://nextjs.org/) (React Framework)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (Modern Design System)
- **AI Core**: JavaScript Random Forest Implementation (`ml-random-forest`)
- **Data Visualization**: [Recharts](https://recharts.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)

## 🚀 Quick Start

### 1. Clone Repository
```bash
git clone https://github.com/Sohaildevv/Delivery-Mode-Prediction-ML-MaternalAI.git
cd Delivery-Mode-Prediction-ML-MaternalAI
```

### 2. Prerequisites & Setup
- **Install Node.js**: Ensure Node.js (v18 or higher recommended) is installed from [nodejs.org](https://nodejs.org/).
- **Install Dependencies**:
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Open Application
Navigate to [http://localhost:3000](http://localhost:3000) in your browser.

> 💡 For a detailed step-by-step beginner guide, please see [SETUP_GUIDE.md](./SETUP_GUIDE.md).
