# 🏥 MaternalAI: Clinical Mode Prediction System

MaternalAI is a specialized full-stack application designed to predict maternal delivery outcomes using machine learning. Developed by **Azhar Nawaz** and team (Final Year Pharmacy Students), this platform integrates pharmaceutical expertise with state-of-the-art AI.

![MaternalAI Banner](https://images.unsplash.com/photo-1584036561566-baf8f5f1b144?q=80&w=2000&auto=format&fit=crop)

## ✨ Features

- **🤖 AI Diagnostics**: Real-time Random Forest classification for delivery mode risk assessment.
- **📊 Analytics Dashboard**: Interactive visualizations of physiological data and model performance.
- **🔐 Secure Access**: Localized authentication system ensuring data integrity.
- **📄 Clinical Reports**: Print-ready diagnostic reports for clinical documentation.
- **📱 Responsive Design**: Fully optimized for mobile, tablet, and desktop viewing.

## 🛠️ Tech Stack

- **Frontend/Backend**: Next.js 14 (React Framework)
- **Styling**: Tailwind CSS (Modern Design System)
- **AI Core**: JavaScript Random Forest Implementation
- **Icons**: Lucide React
- **Animations**: Framer Motion

## 🚀 Quick Start

1. **Install Node.js**: Download from [nodejs.org](https://nodejs.org/).
2. **Install Libraries**: Open the folder in a terminal and run `npm install`.
3. **Run App**: Run `npm run dev`.
4. **View**: Open `http://localhost:3000` in your browser.

> For a detailed step-by-step guide for non-developers, please see [SETUP_GUIDE.md](./SETUP_GUIDE.md).
